## 📌 Problem Statement
Hospitality venues face unpredictable emergencies where critical information is often siloed. Fragmentation between guests, staff, and first responders leads to delayed actions. 

**RCR** eliminates these silos by creating a **highly reliable bridge** for instantaneous crisis detection and synchronized response efforts across a decentralized ecosystem.

### 🔑 Critical Features:
* **Crisis Severity Distribution:** Interactive pie charts identifying emergency types (Medical, Fire, Security).
* **Live Resource Mapping:** Real-time visualization of the nearest emergency personnel.
* **Trend Forecasting:** Historical data analysis to predict peak risk periods.

## 🛠️ Tech Stack & Architecture
* **Frontend:** Streamlit (Professional Dark-Purple Theme)
* **Data Processing:** Pandas, NumPy
* **Visualization:** Seaborn, Matplotlib, Plotly
* **Backend Logic:** Python 3.9+
* **Real-time Sync:** WebSockets for instant alerts
